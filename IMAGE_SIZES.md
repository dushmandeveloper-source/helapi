# Hela Api Website — Required Image Sizes

Please supply images at the sizes below. All sizes are in pixels (width x height).
Format: JPG or PNG, optimized for web (keep file size under ~500KB each where possible).

---

## 1. Homepage Hero Banner (rotating slider)

- **Size:** 1920 x 800 px
- **Aspect ratio:** 2.4 : 1
- **Used on:** Home page, top rotating banner
- **Notes:** Keep the main subject centered — edges may be cropped slightly on very wide or very narrow screens.

## 2. Page Header Banners (About Us / Contact Us / Services / Products)

- **Size:** 1920 x 480 px
- **Aspect ratio:** 4 : 1
- **Used on:** Top section of About Us, Contact Us, Services, and Products pages
- **Notes:** This is a short, wide strip — avoid images where the subject is centered vertically in a tall frame, as top/bottom will be cropped.

## 3. "Explore Our Collections" Category Cards (Homepage)

- **Size:** 900 x 700 px
- **Aspect ratio:** 9 : 7 (approx. 1.29 : 1)
- **Used on:** Home page, "Explore Our Collections" section (Tea, Spices, Herbs, Heritage, etc.)
- **Notes:** All category images should use the same aspect ratio. Currently some images are landscape and some are portrait, causing inconsistent cropping between cards — please supply all in the same 900 x 700 ratio.
